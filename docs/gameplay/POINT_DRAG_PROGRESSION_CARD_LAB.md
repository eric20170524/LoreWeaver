# 点位拖拽进度 Card Lab

第二十二张 `point_drag_progression` 使用共享 RuntimeKernel / core Adapter，入口 `?card=point_drag_progression`。默认进度目标 100、匹配基础增益 14、失稳上限 100；错配增加 18 失稳并保留原本 `nearMatchProgress × 0.35` 的少量进度，画布内落空增加 8 失稳。失稳每秒恢复 4，满时失败；达到进度目标成功。没有生命或限时失败。

修复落空满失稳后提前返回而被衰减救回、同次操作满失稳与达标时先判胜、隐藏点位仍接收投放、初始点位显示和阶段不一致、随机能量球无法匹配当前可见点位、随机池位置重叠、暂停拖拽/释放生效，以及结束后对象/监听器引用残留。失稳失败优先，宿主 goalValue=0，由实际进度判胜，避免分数在自定义增益下提前完成。

阶段阈值默认按目标的 33%、66%、100% 缩放，支持原目录 30–200 进度。开始开放三个点位，随后开放第四、第五个；只生成当前可匹配的元素。能量池最多六球，使用固定间距空槽，补球复用空槽。路径顺滑加成保留，重新开始拖拽重置为 1，路径采样只保留计算所需的最后三个点。默认直线鼠标拖拽通常获得约 1.2 倍增益；键盘操作使用基础增益。

鼠标/触屏拖拽，或数字键先选球槽编号，再选点位编号；Esc、画布外释放和暂停会取消拖拽并将球放回原位，不计落空。画布内无目标放下仍按规则消耗球并加失稳。分支奖励按真实匹配权重选择，零匹配贡献不会默认授予木分支。
