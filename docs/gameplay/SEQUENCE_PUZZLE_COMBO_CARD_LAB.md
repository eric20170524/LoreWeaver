# 顺序拼图组合 Card Lab

第十九张 `sequence_puzzle_combo` 使用共享 RuntimeKernel / core Adapter，入口 `?card=sequence_puzzle_combo`。先观察黄色闪灯并复现顺序，再把编号碎片放入同号槽位。默认 4 灯、4 块，两个参数均支持既有 2–8 范围。答错重新演示，放错可重试，没有生命或限时失败，只有撤退。

修复演示中也可作答、完成顺序后的 400ms 切换窗口仍能改写状态、重复创建第二阶段、暂停拖拽/释放生效、画布外遗留拖拽、完成时清理后继续访问 UI，以及演示 timer/监听器/对象引用残留。分数与完成进度一致，错误归零、完整两阶段达到 100 才成功。

演示、作答、切换、拼图四种输入状态分别受限。碎片使用随机排列的固定间距位置，替代可能重叠的随机散点；八种颜色和清晰编号匹配槽位，避免超过六块时颜色重复。放错、无槽位、画布外松手或暂停会把未放置碎片恢复到可触及的起点。所有图形避开宿主 HUD。

鼠标/触屏支持点灯和拖拽。数字键 1–8 可完成两个阶段：按序作答；拼图时第一次选碎片、第二次选目标槽。按 DOM 事件对象去重，不忽略两个独立的相同数字短按。已放置碎片不能再次选择。

```sh
node productize/jobs/check-combo-runtime.mjs
node productize/jobs/run-combo-card-lab-e2e.mjs
npx tsc --noEmit
```

八项状态机回归覆盖演示拒绝输入和错误重播、切换竞态、暂停取消拖拽、错误槽位/画布外释放、成功及同步销毁、最大八块布局、键盘两阶段与重复事件、参数和权限/清理。

浏览器六场景覆盖默认鼠标两阶段、错误顺序与错误槽位重试、暂停/画布外释放/三次重开、最大八灯八块键盘通关、390px 触屏通关和 file:// 离线通关。脚本通过 activeLamp 与 demoOrdinal 观察实际可见亮灯，逐个记录包括重复亮灯在内的顺序；快照不暴露隐藏答案数组。拼图按可见编号执行真实拖拽或键盘输入，不直接写状态、不调用胜利。
