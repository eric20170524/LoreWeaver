# 闪避采集波次 Card Lab

第十八张 `hazard_collect_waves` 使用共享 RuntimeKernel / core Adapter，入口 `?card=hazard_collect_waves`。默认三波，每波 15 秒，分别要求 4、5、6 颗能量珠。黄色预警结束后落雷造成 20 伤害，并生成蓝色能量珠；点击或靠近采集，回复 3 生命。收集够数量仍须等待本波截止，最后一波满足目标才成功。缺少数量、生命耗尽和撤退有各自结果原因。

修复暂停/过期拾取回调仍可采集、零生命回退为 100、遍历障碍时死亡销毁场景后继续访问对象、输入监听/Key/UI/数组引用残留。先完成伤害迭代，再结算死亡，致命伤害不会被同帧采集回血救回。宿主 goalValue=0，采集分数不能提前触发胜利；波次状态决定结算。

移动支持按住指针拖动及 WASD/方向键，空悬鼠标不再移动角色。场地和预警区避开宿主 HUD，移动夹紧边界；点击能量珠的原有采集方式保留。暂停同时冻结时间、移动、采集。保留跨波尚未采集的能量珠，上限 64，超过时移除最老的对象，避免高频长关卡堆积。

六项参数公开在试验场：波数、每波时间、首波目标、预警、伤害和间隔。目录限制有限范围，试验场拒绝不足以生成最终波目标的组合；直接调用适配器时，时间至少为 `(首波目标 + 波数 - 1) × 间隔 + 预警 + 0.2 秒`，向上取到 0.1 秒。默认配置仍为完整 45 秒。
