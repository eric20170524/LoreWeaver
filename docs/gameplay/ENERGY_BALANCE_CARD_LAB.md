# 第九张玩法卡：energy_balance

构建 Card Lab 后打开 `?card=energy_balance`。把元素拖入圆心以纠正指针：木/水向左，火/金/土向右；指针在绿色区域时累计稳定时间。默认累计 20 秒获胜，越过警戒范围连续 8 秒消耗一次容错，五次容错耗尽失败。

可配置目标稳定时间、安全区宽度、容错次数/越界时长、元素生成间隔。表单拒绝最长间隔小于最短间隔，runtime 也将非有限值和越界值规范到卡片范围。该卡不按 HP 或无关宿主分数判胜。

原实现从精确平衡点出发，漂移公式在此恒为零，默认可全程不操作获胜。现在默认漂移包含一个微小方向压力，随后保留偏离中心时加快的趋势；玩家需要反向元素纠正。放宽安全区或缩短目标的自定义配置仍可能降低操作需求，不声明所有参数组合难度相同。

同时修复：暂停中拖拽改变状态、退出残留全局输入监听、未销毁元素文字、无限堆积元素。最多保留 12 个元素，回收时同时释放图形和文字；已开始拖拽的元素不会被优先回收，画布外松手取消拖拽。局部 timer/input 由当前 Adapter 生命周期负责清理。

```sh
node --test productize/jobs/check-energy-balance-runtime.mjs
node productize/jobs/run-energy-card-lab-e2e.mjs
```
