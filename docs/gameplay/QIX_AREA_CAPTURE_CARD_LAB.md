# 区域占领 Card Lab

第二十一张 `qix_area_capture` 使用共享 RuntimeKernel / core Adapter，入口 `?card=qix_area_capture`。默认 24×16 网格、2 个敌人、90 秒时限，内部区域占领 70% 获胜。WASD/方向键逐格移动，或点击目的格自动逐格靠近；灰色边框、蓝色区域安全，进入空白画黄线，返回安全区闭合。敌人碰到未完成路径扣 20 生命并返回左侧起点；五次断线耗尽默认生命，或超时未达标失败。

修复安全边框未参与洪水填充、用多边形中点/全图 45% 阈值猜测区域的逻辑。边框和完成的路径作为阻隔，从所有敌人所在区域扩展，填充其余无敌人区域。占领比例只计算内部格，不把边框计入进度。两侧都有敌人时保留两侧空白，只计路径；没有敌人时闭合合法路径会占领剩余区域。闭合前检查敌人位于路径，避免把敌人误封在已占领格中。

敌人按轴检测安全格，碰撞时恢复该轴原位置再反向；移动按步长细分避免高速穿越。画线碰撞按网格归一距离检测，适配非正方形格子。回撤到起点、过短路径返回安全区都取消画线；拒绝斜向/跨格动作。受击清空旧指针目的地，不再自动重新进入危险区。死亡/胜利立即退出更新，避免同步关闭场景后的 UI 访问。暂停输入、键盘 Key、监听器、图形与敌人引用清理齐全。

公开参数包括占领比例、网格、敌人数、时限、移动/敌人速度和闭合长度。保留目录最大 48×36、8 敌人、95% 目标和 300 秒时限，正确支持 enemyCount=0；默认移动节奏维持每 0.12 秒一格，playerSpeed 相对基准 140 缩放间隔。宿主 goalValue=0，由精确面积比例结算，避免整数分数提前获胜。

九项状态机回归覆盖超过 45% 的无敌人区域、多个敌人区域、零敌人和同步销毁、回撤与斜向拒绝、过短闭合、碰撞扣血和目的地取消、敌人反弹不滞留已占领格、致死/超时清理、暂停输入/最大参数/零生命。

浏览器七场景：默认键盘 70% 通关、默认五次实际碰线死亡、配置 20 秒自然超时、暂停未闭合路径和零敌人通关/三次重开、48×36 最大网格零敌人 95% 目标通关、390px 默认触屏通关、file:// 默认离线通关。最大网格的浏览器胜利使用零敌人，未冒称最大八敌人挑战已通关；默认胜利均保留两敌人和 70% 目标。

浏览器根据公开可见的占领图、敌人位置和速度规划安全区路线及直线切割，预测运动以避免碰线，再发送真实键盘或指针输入。没有改写状态、瞬移、暂停敌人进行切割、降低默认目标或加速时间。路径规划与运行时区域计算各自执行，最终只检查真实 NodeResult 和实际占领率。
